# ATM Simulator System

A Java-based ATM Simulator System that mimics real banking ATM operations.  
This project allows users to perform banking transactions such as login, balance inquiry, cash withdrawal, deposit, mini statement generation, and PIN change through a graphical user interface.

---

## Features

- User Authentication
- Balance Inquiry
- Cash Withdrawal
- Cash Deposit
- PIN Change
- Mini Statement
- Fast Cash
- Transaction History
- Secure Banking Operations
- Java Swing GUI

---

## Technologies Used

- Java
- Java Swing
- JDBC
- MySQL Database
- NetBeans IDE
